# Boss and guide navigation

Reader navigation groups fight overviews, combat methods, AFK methods, achievements and reference guides under their boss. This metadata is derived from the existing source paths and boss aliases; captured guide bodies and source records are unchanged.

The guide library has one **Boss guides** topic with alphabetical boss groups. Existing `Boss methods`, `Boss fundamentals` and `Advanced boss guides` topic URLs restore to that topic. Other topic choices still filter the relevant guide types. Global search uses the same boss membership and groups matching guides beneath a link to all of that boss's guides.

Every boss hub includes its complete catalogue, retaining the existing curated ordering where available. Individual guides and their readable aliases expose a boss breadcrumb and a collapsed guide switcher. Guide IDs, source URLs, reader URLs and Saved identities stay unchanged.

The motivating regression is Ghrazi Blood Knights: searching `ghrazi` or `gbk` finds both the fight overview and the 100% ranged/melee method. Automated checks also cover typo handling, all 45 hub inventories, legacy topic URLs, single-guide aliases and the Kerapac, Raksha, Arch-Glacor and Rasial catalogues.

Browser verification on a remote preview is still required; the cloud Chrome environment cannot reach the executor's localhost server. Automated layout/theme checks are not a physical-device or screen-reader test.
